# Chaverim of Union County Website

Static multi-page website for Chaverim of Union County.

## Pages
- `index.html` — Home and services overview
- `donate.html` — Donation form page
- `volunteer.html` — Volunteer recruitment page
- `coverage.html` — Coverage map page

## Local preview
Open `index.html` directly in a browser, or run a simple static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
